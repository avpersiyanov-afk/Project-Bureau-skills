# Project-Bureau-skills

Less clicking. More engineering.

Самостоятельное расширение pyRevit со вкладкой **«Бюро» → панель «Инструменты»**.
Не зависит от расширения LowLife — весь нужный код (`lib/pbtools/`) лежит внутри.

## Установка

pyRevit → Settings → Custom Extension Directories → добавить путь к этой папке
(`...\Project-Bureau-skills`), затем Reload. pyRevit найдёт вложенную
`ProjectBureau.extension`.

Либо клонировать сразу в папку расширений pyRevit:

```
git clone https://github.com/avpersiyanov-afk/Project-Bureau-skills.git
```

## Состав панели «Инструменты»

| Кнопка | Назначение |
|---|---|
| Размеры по осям | Простановка размеров по сетке осей |
| Длина Generic Model | Запись длины обобщённых моделей в параметр |
| Загрузка семейств из каталога | Загрузка `.rfa` из папки-каталога с метками даты |
| Семейства из каталога | Мониторинг актуальности и обновление семейств на месте |
| Запись номера помещения | Перенос помещения из связанной модели по маске параметров (Shift+клик — настройки/прогон по видам) |
| Марки помещений | Расстановка и починка марок помещений из связи (Shift+клик — несколько видов) |
| Экспорт в Эксель | Выгрузка спецификации в `.xlsx` (без openpyxl/Excel) |
| Импорт из Эксель | Загрузка правок из `.xlsx` обратно в модель по «Revit ID» |
| Разбить спецификацию | Разбивка спецификации на листе на участки заданной высоты |
| Переименование по списку | Парное переименование файлов в двух подпапках по редактируемому списку соответствий |

## Происхождение

Форк панели `Tools.panel` из [LowLife](https://github.com/avpersiyanov-afk/LowLife).
Пакет `lowlife` переименован в `pbtools`, чтобы не конфликтовать, если оба
расширения установлены рядом. Репозитории независимы — правки при необходимости
вносятся в оба.
